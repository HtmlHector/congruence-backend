# Security Policy

## Supported Versions

Only the latest release of `parabox-backend-starter` receives active security updates and vulnerability patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a security vulnerability in Parabox Backend Starter, please do **NOT** open a public issue.

Instead, please send an email to **security@parabox.so** including:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept demonstrating the issue.
- Any suggested fixes or remediations.

### Response Timeline
- We will acknowledge receipt of your report within 48 hours.
- We will provide a triage assessment and estimated fix timeline within 5 business days.
- A public security advisory and patch release will be coordinated once the vulnerability is resolved.
